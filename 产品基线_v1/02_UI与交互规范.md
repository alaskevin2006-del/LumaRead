# UI 与交互规范 v1.0

配套 `UI/index.html` 可视化画册、`UI/screens/` 独立 PNG、`UI/source/` 静态可编辑排版源文件。共 34 张：学生端 22 张，管理端 12 张。源文件是设计产物，不是可用的业务应用；按钮不具备登录、录音、保存等真实功能。

## 1. 设计原则

一句话：让学生每次只需判断“听、读、继续”，让管理员知道“哪一页还没准备好”。

保留旧方案的绘本图像、听读、逐词反馈与打卡主线，但交付文件完全独立。新的深青绿与奶油白视觉针对机构内小学及以下学生，兼顾高年级，不采用过度幼儿化装饰。书名和正文用英语，导航、任务提示用中文。

## 2. 响应式、可读性与媒体

学生端：360–599 px 一栏，底部操作区考虑系统安全区；600–1023 px 内容居中、限制阅读行宽；≥1024 px 阅读区可图文左右分栏，但操作顺序不变。正文滚动到末尾时，最后一行必须能完全露出固定按钮上方。支持系统字体放大，不能固定容器裁掉文本。

管理端：优先桌面 ≥1280 px；1024–1279 px 缩窄页目录并让表单区独立滚动；更窄屏只展示资源概览与“请在电脑编辑”提示，不强塞三栏。

封面卡片可以裁切。真实绘本页面可能包含印刷文字，必须完整显示（contain）并支持点开大图，不能按装饰插画裁切。本套示例是无印刷文字的原创插画，所以使用了适当裁切；正式页面需按媒体类型选择。

原文无词时间戳时不做逐词播放跟随；单词颜色对应评分结果，不代表正在播放位置。正文可以有长词、重复词、标点，前端按后端 token 坐标渲染，不以文本查找替代定位。

评分不只依赖颜色：红色实线、橙色虚线、绿色无下划线；不确定为灰色。图标有辅助标签和焦点态；视觉图中的点按图标在实现时必须具备可访问名称。弹层打开锁定背景焦点，关闭恢复触发控件。

## 3. 核心页面行为

| 页面 | 进入条件 | 主操作 | 返回/完成 |
|---|---|---|---|
| 登录 | 无会话 | 登录 | 普通学生进入首页，首次临时密码进入改密 |
| 首页 | 已登录 | 继续最近未完成轮次，或选书 | 底栏切换 |
| 绘本库 | 已登录 | 搜索、等级筛选、打开详情 | 搜索状态可保留 |
| 详情 | 发布资源或本人可访问历史版本 | 开始/继续/再读 | 听第一页不产生进度或打卡 |
| 阅读 | 有阅读轮次与固定版本 | 听本页、跟读、翻页 | 返回保存最近浏览页 |
| 评分结果 | 有有效结果 | 再读或下一页 | 重读成功替换展示值，保留历史 |
| 完成检查 | 末页点击完成 | 补齐未练习页 | 全部齐全才进入完成页 |
| 完成页 | 服务端确认完成 | 去选下一本 | 当天唯一打卡，由服务端产生 |
| 我的学习 | 已登录 | 日历、记录、设置 | 不提供同伴排名 |
| 阅读记录 | 已登录 | 续读未完成轮次，查看已完成摘要 | 再读开新轮次，不覆盖旧轮次 |
| 内容列表 | 管理员 | 新建、编辑、预览、下架 | 成功后列表状态即时更新 |
| 资源编辑 | 草稿版本 | 校对、音频、保存 | 有未保存修改时离开确认 |
| 发布检查 | 草稿准备就绪 | 跳转问题页或发布 | 成功回列表并提示“已发布” |
| 账号管理 | 管理员 | 创建、重置密码、停用 | 明确提示对会话的影响 |
| 评分测试 | 管理员 | 上传/录音并评测 | 不写学生进度和打卡 |

## 4. 阅读状态机

```text
ready ──听原音──> playing ──暂停/结束──> ready
ready/playing ──开始跟读──> permission-request（仅按需）
permission granted ──> recording ──读完了──> uploading ──> evaluating
evaluating ──有效结果──> result ──再读──> recording
evaluating ──服务失败──> retryable-error ──重试同一任务──> evaluating
evaluating ──静音/严重不确定──> unscorable ──重新录音──> recording
recording ──离开──> discard-confirm ──继续──> recording
任何非录音状态 ──翻页──> 相邻页对应状态
```

上传阶段文案“正在上传录音”，服务已接收后为“正在评分”；两者复用 S07 布局，但不能在上传未成功时写“录音已上传”。结果或进度只绑定发起任务的页和轮次，旧请求迟到不能覆盖当前页。

录音中页面按钮文案“读完了”；评分后“再读本页”；下一页与上一页处于独立翻页栏。第 1 页隐藏上一页，最后一页右侧变为“完成本书”。展示页不出现录音按钮，保留翻页；不误显示零分。

## 5. 异常与复用状态

| 情况 | 具体反馈 | 恢复操作 | 设计依据 |
|---|---|---|---|
| 首次无历史 | 首页继续卡改为“选一本开始” | 去绘本库 | S02 变体 |
| 未发布任何书 | “老师正在准备故事” | 返回首页，不展示假书 | S16 空态变体 |
| 无搜索结果 | “还没找到这个故事” | 清除搜索 | S16 |
| 登录账号或密码错误 | 表单下“账号或密码不正确” | 保留账号、清空密码 | S01/A01 行内错误 |
| 账号停用 | “账号暂不可用，请联系机构” | 返回登录 | S01 变体 |
| 两次密码不同 | 确认框下“与新密码不一致” | 修改输入 | S15 行内错误 |
| 初次录音告知 | “声音用于本次评分，默认保存 30 天” | 同意后请求浏览器权限；暂不录音 | S09 底部弹层复用，正文替换 |
| 麦克风拒绝 | 说明浏览器设置路径 | 已开启重试 / 先听 | S09 |
| 无录音设备或不支持 | “当前浏览器无法录音” | 用系统浏览器打开；仍可听读 | S09 变体 |
| 录音后台中断 | “录音已中断，请重新录制” | 重录，未完成不记分 | S19 变体 |
| 上传或评分失败 | 不判零分、不造词颜色 | 原录音可用时重试；否则重录 | S10 |
| 评分很慢 | 15 秒说明等待；60 秒可重试 | 防重复任务，保留上下文 | S07 → S10 |
| 静音、严重噪声 | “这次没有听清楚” | 靠近麦克风重录 | S19 |
| 完全无关句子 | “请跟着本页文字再读一次” | 听原音后重录 | S19 变体 |
| 少数词无法评分 | 该词灰色，必要时短说明 | 可重读，也可下一页 | S08 变体 |
| 重读失败已有旧分 | “这次未评分，显示上次结果” | 旧分保留，本次重试 | S08 + S10 |
| 原音失败 | 独立媒体错误提示 | 重试原音 / 返回阅读 | S18 |
| 缺练习页 | 列出缺页及原因 | 进入第一张未练习页 | S11 |
| 网络断开 | 顶部短提示“网络已断开” | 恢复后重试；不假打卡 | 当前页通用条幅 |
| 登录过期 | 恢复登录后回原书/页 | 已上传任务继续，未上传录音可丢失 | S01 复用 |
| PDF 处理部分失败 | 显示已完成页与失败页 | 重试失败页，或手工补图文 | A11 |
| 草稿保存失败 | 顶部“保存失败，内容仍在当前页” | 重试；离开需确认 | A04 行内状态 |
| 上传文件超限/格式错误 | 显示具体限制 | 重新选择文件 | A03 行内状态 |
| 发布校验不通过 | 列出阻断项与页码 | 跳转处理 | A05 |
| 发布成功 | “绘本已发布，学生现在可以阅读” | 返回列表 | A12 → A02 |
| 无权限 | “当前账号没有管理权限” | 返回学生端 / 重新登录 | 全页简洁错误态，无管理数据 |

这些复用状态的结构已由对应图确定，文字和行为由表格约束，不为同一组件每一句错误文案重复导出图片。

## 6. 管理表单约束

明确区分保存与发布。草稿可以不完整，发布必须完整。页面校对勾选在文本、图片或音频配置改变后重新置为未确认。音频区间支持毫秒，用户界面显示 `mm:ss.SSS`；修改起止时间后试听按钮播放新范围。

新建学生登录名唯一，使用 3–32 位字母、数字或下划线，显示名称 1–30 字。密码初始基线 8–64 位、至少字母和数字，禁止在日志与列表中显示；正式认证策略可由机构调整。临时密码仅创建/重置成功时一次性展示，不能查询明文历史密码。

停用、重置密码、删除草稿复用 A10 确认框：分别写明“终止当前会话”“下次需改密”“草稿删除无法撤销”。普通保存不反复确认。发生并发编辑冲突时保留本地编辑并提示重新加载比较，禁止悄悄覆盖新版本。

## 7. 图片与交付

PNG 是主要评审文件。`source/*.html` 保留精确中文排版，`source/build.cjs` 是静态导出辅助文件；没有业务 API、数据库或实际账号。

`assets/sample-book.png` 由内置 image_gen 工具生成，为新设计专用原创示例插画；提示词见 `参考资料/图像生成说明.md`。其余封面是排版示例，不代表新增真实课程。设计阶段不复用旧图中的书封面素材。

页面完整索引见 `04_页面索引.md`；检查记录见 `05_交付检查.md`。
