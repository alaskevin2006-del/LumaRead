# 管理后台操作更新（2026-10-19）

- 教学资源合并为单一列表，移除统计卡片、等级设置和侧栏评分入口。草稿可编辑、发布、删除；已发布可下架为草稿。删除曾发布的书目采用隐藏方式，历史版本和学生记录保留。
- 页面支持指定位置插入、拖动排序、删除，音频随页面移动。编辑停顿后自动保存，切页时先保存。空白新页默认展示页；PDF 中无英文的页面默认展示页。
- 页面允许缺少文字或音频，跟读页必须有参考文本。完全空页不可发布；整本至少有一页并具备封面（默认使用页面图片）。不再强制逐页确认。纯展示绘本也可以完成阅读。
- 绘本顶部提供音频管理：整本音频上传一次、播放时标记分页并调整秒数；分页文件批量上传、数字排序、选择起始页、跳过展示页、手动匹配。默认不覆盖已有音频，须明确勾选。失败只重传失败文件；绑定整体校验后提交。
- 音频采用共享源文件及各页时间区间，不重复上传或存储整本音频。本轮未加入自动语音对齐或生成逐页裁剪文件。
- 试读评分在具体绘本内，自动使用当前页文本，属于可选测试，不影响发布或学生记录。仍需配置真实评分服务。
- 学生支持 Excel (.xlsx)、CSV、Excel 粘贴导入与修改预览。姓名必填，账号可自动生成。每批最多 200 人，重复账号不部分导入。可搜索班级、多选、批量启停、调整班级、重置密码及导出。密码只在生成时提供下载。
- 部署前运行 `alembic upgrade head`，新增 `0002` 学生班级字段。后端新增 openpyxl 依赖。已部署到 124.221.230.69:8443，运行镜像标签 admin-105e3e7。
