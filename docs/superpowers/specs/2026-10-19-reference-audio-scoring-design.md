# 以机构标准音频为参照的跟读比对

状态：待审阅的设计，尚未实现或部署。2026-10-19。

## 目标与选型

以学生发音内容与机构上传音频的贴合程度为首要目标，响应速度其次。不评估是否符合泛化的母语标准，不比较说话人身份，不要求儿童模仿成人音色。选择 microsoft/wavlm-large 的最后一层逐帧语音特征，使用余弦距离与动态时间规整（DTW）。这是有相关研究依据的候选基线，不宣称其为全行业最准确模型或已通过儿童验证。

依据：
- https://huggingface.co/microsoft/wavlm-large
- https://arxiv.org/html/2607.13721v1 （论文描述最后一层 WavLM-Large 特征、余弦距离及按路径长度归一化的 DTW；论文中的多参考音频结果不能直接套用到本产品单参考场景。）

不使用语音转文字后的字符串相似度充当发音评分。不使用说话人识别微调版本。模型公开权重和所选运行依赖的许可证须在固定版本时核对并保留。

## 输入、处理与输出

输入为学生录音和该页已保存的原音区间。原音来自同一绘本已授权的媒体资产，不允许客户端提交任意服务器路径或外部 URL。后台试读同样传页面标识，由服务端读取音频区间。

统一为 16 kHz 单声道；检测空录音、截断、严重削波和异常时长。只去除首尾静音，保留内部停顿。标准音频无有效语音时明确要求管理员更换，不能生成成绩。

标准音频按页提取特征并缓存，键包含音频内容摘要、起止时间、模型固定修订号及预处理版本。学生端仅需计算新录音特征。使用 DTW 对齐不同语速，比较逐帧发音特征，输出归一化距离和相似度指数。指数拟采用 100×clip(1-平均余弦距离,0,1)，是算法指标，不是正确率；是否适宜展示百分制须通过样例检查，不设置未经验证的及格线。

首版展示整体音频相似度与参考音频时间轴上的片段偏离，不把时间片段伪装成逐词纠错。展示参考与学生录音的对应回放位置。文字用于阅读，不作为唯一判定标准；精确逐词反馈留待有可靠文本对齐时实现。语速比例可单独展示，不武断加入总分。语调评分不在首版伪造输出。

质量差或无法可靠对齐时返回可解释的失败原因和重录建议，不强行打低分。所有结果记录模型、预处理和评分方法版本，标明尚未经过儿童样例标定。

## 与 LumaRead 的集成

新增 reference_similarity 模式，保留现有 Azure/remote 模式及历史结果。任务提交时固化参考音频资产、时间区间和模型版本，后台编辑后不改变已提交任务的评分基准。评分结果按模式校验；新模式不要求伪造完整逐词分数，前端不绘制旧的红绿词标记，不展示没有计算的准确度、流利度、完整度。

新模式下缺少标准音频的页面保留阅读功能，不调用比对；发布检查明确列出不能跟读的页面。新阅读轮次须固化可练习页集合与评分模式，完成条件只包含有效标准音频的练习页。历史轮次维持原规则，避免切换服务改变已开始任务的完成条件。

参考特征预热失败仅影响相关页面的比对，不阻止其他阅读。评分请求通过原有队列，单实例处理，防止并发加载多份大模型。服务超时可重试，相同任务幂等，不写入模拟分数。

## 部署与边界

独立 LumaRead 比对容器，无公网端口、无其他项目挂载。权重持久化，固定模型版本；先在限额容器检查加载峰值、短句和最长录音时延，之后再决定能否在当前机器正式开启。首次加载或验证期间不更改现有生产评分配置。

当前实测服务器 2 核、3723 MB 内存，约 2530 MB 可用；未检测到 nvidia-smi，不能视为已确认可用 GPU。模型权重大小不等于运行内存。不得为适应资源限制而静默更换小模型、降低采样精度或调整评分公式。若大模型在安全限额内无法工作，保留完成的适配与部署文件，报告实测结果，再选择独立资源，不能挤占其他项目或自动购买服务器。

原音缓存、单实例常驻、排队、超时、日志和资源限额均可配置。优先尝试精度不变的性能优化。量化或分块推理会改变结果，只能在独立对照实验通过后启用。

## 验证与正式启用条件

1. 同一录音与自身比对应接近指数上限；空音频、静音、损坏文件必须拒绝。
2. 音量与首尾静音变化不能导致大幅变分；相同句子的正常语速变化应可对齐。
3. 不同说话人读同一句、同一说话人读不同句必须交叉比较，避免算法主要在比较声纹。
4. 漏词、替换、重复和无关句子能否形成可区分的距离，需要真实录音验证；不得仅用自身比对证明准确。
5. 儿童与成人读同一句需单独检验；现有服务器有原音，但未确认存在可用的儿童验收样例。
6. 记录实际内存峰值与短、中、长录音的端到端时间，验证并发排队不影响其他网站。
7. 回归授权、参考片段绑定、任务重试、历史轮次、无音频页面、完成记录及 UI 文案。不得将外部算法输出直接当作 Azure 分数。
8. 技术测试通过可开放管理员试读。面向学生正式启用前，需要确认真实样例上的区分效果；若样例不足，只能称为实验比对。
